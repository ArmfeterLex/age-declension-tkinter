# Age Declension Tkinter

Простая программа на Python с графическим интерфейсом для правильного склонения слова "год" в зависимости от введённого числа.

## Функциональность

- Ввод числа от 1 до 99
- Автоматическое определение правильного склонения: год/года/лет
- Обработка ошибок ввода (не число, вне диапазона)
- Простой и понятный интерфейс

## Интерфейс

- Поле ввода для возраста
- Кнопка "Показать"
- Метка для вывода результата
- Всплывающие окна с ошибками

## Логика склонения

def get_year_word(k):
    if 11 <= k % 100 <= 14:
        return "лет"
    elif k % 10 == 1:
        return "год"
    elif 2 <= k % 10 <= 4:
        return "года"
    else:
        return "лет"

## Пример работы

Ввод: 1 → Мне 1 год
Ввод: 2 → Мне 2 года
Ввод: 5 → Мне 5 лет
Ввод: 21 → Мне 21 год
Ввод: 23 → Мне 23 года
Ввод: 25 → Мне 25 лет
Ввод: 111 → Ошибка (введите 1-99)

## Требования

- Python 3.x
- tkinter (входит в стандартную поставку Python)

## Примечание

Программа учитывает особый случай чисел 11-14, где всегда используется "лет" независимо от последней цифры.
